# nothing.tech — Design Map + Taste DNA

Fuente: https://nothing.tech (captura 2026-10-04, viewport 1440×900, una página). Referencia visual para las presentaciones de `laboratorios/`.

## Design Map

| Token | Valor medido |
|---|---|
| Negro base | `#040404` (texto sobre claro y fondo de héroe) |
| Gris claro de sección | `#F4F4F4` |
| Gris línea | `#D8D9D9` |
| Gris texto secundario | `#595A5A` · `#B1B3B3` sobre oscuro |
| Acento | rojo del producto (cuadrado rojo en el auricular) y `#FFC700` puntual (1 aparición) |
| Display de marca | `Ndot` (dot-matrix), logo y nombres de producto |
| Titular | `NType82` (serif editorial estrecho), 40–48 px |
| Etiquetas y botones | `LatteraMono` / `Geist Mono`, 11–12 px, MAYÚSCULAS (36 de 48 textos) |
| Tracking | `normal` en todo; la personalidad viene de la familia, no del espaciado |
| Radios | 0 px (54 elementos), 4–6 px en botones y tarjetas de producto |
| Superficies | translúcidas: `rgba(255,255,255,.05)` sobre negro, `rgba(89,90,90,.05)` sobre claro |
| Fondo | rejilla de puntos de ~113 px, apenas visible, en secciones claras y oscuras |

## Taste DNA

1. **Tres voces tipográficas con roles fijos.** Trigger: necesitan parecer hardware y a la vez editorial. Decision: dot-matrix solo para marca/nombres, serif para la frase que se lee, mono mayúsculas para todo lo que es dato o control. Reason: cada familia dice qué tipo de texto es antes de leerlo. Evidence: 14 textos mono 11 px, 11 en NType82, 8 en Ndot.
2. **La rejilla de puntos como material, no como decoración.** Trigger: la identidad sale del LED dot-matrix del Glyph. Decision: una retícula de puntos tenue recorre todas las secciones. Reason: traslada el componente físico al lienzo. Evidence: puntos cada ~113 px visibles sobre negro y sobre `#F4F4F4`.
3. **Monocromo con el color racionado (restricción).** Trigger: el producto es el protagonista. Decision: rechazan una paleta de marca amplia; solo negro/blanco/grises y un rojo diminuto. Reason: el color aparece únicamente donde el objeto lo tiene. Evidence: 9 de 10 fondos son grises; el rojo solo en un cuadrado de ~20 px.
4. **Alternancia negro ↔ gris claro por bloques.** Trigger: ritmo en una página larga. Decision: secciones a sangre que cambian de fondo en vez de usar separadores. Reason: el cambio de superficie es el divisor. Evidence: héroe `#040404`, siguiente bloque `#F4F4F4` sin línea entre ambos.
